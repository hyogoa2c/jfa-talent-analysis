# JFA育成経路・指導者ネットワーク定量分析 先行研究調査結果

## 調査対象

[[research_session_2026-06-26_jfa_talent_development|JFA育成経路・指導者ネットワーク定量分析 研究アイディア]] の方針に基づき、以下の論点に近い先行研究・公開資料を確認した。

- 日本人Jリーガーの育成経路
- Jクラブアカデミー、高校、大学、地域クラブ、JFAアカデミーの比較
- 早期の成人プロサッカー出場時間とキャリア成果
- 特別指定選手制度など、日本固有の多経路育成制度
- 指導者接触ネットワークと選手キャリア成果
- クラブ単位の育成投資、若手出場、成績・市場価値

## 暫定結論

調査した範囲では、本研究案と完全に同型の先行研究は見つからなかった。

近い研究・資料は存在するが、多くは以下のように分かれている。

- 育成制度の記述
- 選手評価モデル
- クラブ価値・経営分析
- 試合イベントデータ分析
- 指導者のプレースタイル分析
- 相対年齢効果などのスポーツ科学研究

一方で、本研究案のように、**日本人Jリーガー全体の育成経路、早期出場時間、指導者接触ネットワーク、キャリア到達点を同一データモデルで統合する研究** は、公開情報ベースでは空白がありそうである。

## 近い先行研究・資料

### JFA/Jリーグ特別指定選手制度

JFAは、大学・高校等に在籍したままJクラブ公式戦に出場できる特別指定選手制度を公開している。

この制度は、個人の能力に応じた環境を提供することを目的としており、本研究の以下の仮説と強く関係する。

- H1: 多経路育成仮説
- H2: 早期出場時間仮説

特に、特別指定選手の認定履歴、所属元、受入クラブ、後年のJリーグ出場実績を接続できれば、大学・高校経路から成人プロ環境へ早期接続した選手のキャリア成果を検証できる。

参考:

- JFA 公式「JFA・Jリーグ特別指定選手」: https://www.jfa.jp/youth_development/honor_players/

### JFAアカデミー・トレセン・エリートプログラム

JFA公式サイトでは、JFAアカデミー、ナショナルトレセン、エリートプログラム、特別指定選手制度などが、選手育成事業として整理されている。

これらは制度設計の一次資料として重要である。ただし、公式資料だけでは、個別選手のキャリア到達点との定量的接続は限定的である。

本研究では、制度名を説明変数として扱うだけでなく、以下のような選手単位の履歴データに落とす必要がある。

- JFAアカデミー在籍有無
- トレセン・年代別代表選出歴
- 特別指定選手認定歴
- Jクラブアカデミー所属歴
- 高校・大学経路
- プロ初出場年齢
- U21時点の出場時間

参考:

- JFA 公式「JFAアカデミー」: https://www.jfa.jp/youth_development/jfa_academy/

### 日本サッカーの制度史・学校/大学経路

日本では、Jクラブアカデミーだけでなく、高校・大学サッカーが長く人材供給源として機能してきた。

この点については、制度史・解説レベルの資料は見つかるが、Jリーグ選手単位の大規模パネルデータとして、アカデミー、高校、大学、地域クラブを比較する研究は見つけにくい。

本研究の H1「多経路育成仮説」と H5「経路依存資産仮説」は、この空白を埋める方向で位置づけられる。

参考:

- College soccer における日本の大学サッカー制度の概説: https://en.wikipedia.org/wiki/College_soccer

### 選手評価・予測モデル系研究

試合イベントデータや機械学習を用いて、サッカー選手のパフォーマンスや将来価値を推定する研究は存在する。

代表的なものとして、PlayeRank は試合イベントデータから選手パフォーマンスを評価するフレームワークである。

また、近年は Random Forest、XGBoost、不確実性推定などを用いて、選手の市場価値や将来品質を予測する研究も出ている。

これらは、本研究において以下を設計する際の方法論的参考になる。

- 成果指標の設計
- 出場時間以外のパフォーマンス指標
- 市場価値・移籍金アウトカム
- 機械学習による特徴量寄与の探索
- SHAP などによる説明可能性の確保

ただし、これらの研究は主に選手のパフォーマンス評価・市場価値予測に関心があり、日本固有の育成経路や指導者接触ネットワークを主説明変数としているわけではない。

参考:

- PlayeRank: Data-driven Performance Evaluation and Player Ranking in Soccer via a Machine Learning Approach: https://arxiv.org/abs/1802.04987
- サッカー選手の市場価値・将来品質予測に関する近年の研究例: https://arxiv.org/abs/2502.07528

### 指導者分析・ネットワーク分析系研究

指導者を定量的に扱う研究として、Coach2vec のように、イベントデータから指導者のプレースタイルを埋め込み表現にする研究がある。

これは本研究の H3「指導者ネットワーク仮説」と完全に同じではないが、指導者を定量特徴量化するという点では近い。

一方で、育成年代からプロ入りまでの選手と指導者の接触履歴を二部グラフとして構築し、指導者の中心性・媒介性・ブリッジ性と選手のキャリア成果を結びつける研究は、公開情報ベースでは見つけにくい。

したがって、指導者ネットワーク分析は本研究の中でも特に独自性が出やすい領域である。

参考:

- Coach2vec: Learning Football Coach Representations from Match Event Data: https://arxiv.org/abs/2106.15444

### Jリーグ/日本クラブ経営・価値評価

Jリーグクラブの企業価値や経営に関する研究は存在する。

ただし、これらは必ずしも育成経路、アカデミー投資、自前育成選手比率、若手出場時間を主説明変数としているわけではない。

本研究の H4「クラブ育成投資仮説」を検証する場合、クラブ単位の財務・市場価値・順位データを扱う参考にはなるが、育成投資と競技成績・移籍収入の関係は別途データ構築が必要である。

参考:

- Jリーグクラブの企業価値推定に関する研究例: https://arxiv.org/abs/2406.16773

## 本研究の独自性

### 1. 日本固有の多経路育成を選手単位で定量化する点

Jクラブアカデミー、高校、大学、街クラブ、JFAアカデミーを同一フレームで比較する研究は希少である。

特に、日本では欧州型アカデミーだけでなく、高校・大学・地域クラブがプロ人材供給に関与してきたため、単一のエリート経路ではなく、多経路育成システムとして捉える必要がある。

### 2. 特別指定・U21以前の成人公式戦出場時間をキャリア成果に接続する点

特別指定選手制度などの制度資料は存在するが、制度利用、早期出場時間、後年成果を接続した定量分析は研究余地が大きい。

主なアウトカム候補は以下である。

- プロ初出場年齢
- J1到達
- J1定着
- U21以降の出場時間成長
- 海外移籍
- A代表・年代別代表選出

### 3. 指導者接触ネットワークを導入する点

選手と指導者の接触履歴を構造化し、ネットワーク指標として扱う点は、最も独自性が高い。

具体的には、以下のような指標が考えられる。

- 指導者が関与した選手数
- 後にプロ化した選手数
- 後に代表選出された選手数
- 指導者中心性
- 指導者媒介性
- クラブ・学校・年代代表を横断するブリッジ性

ただし、データ構築コストは高いため、初期研究では選手経路分析を先行させ、指導者ネットワーク分析は第2段階に回すのが現実的である。

## 研究設計への示唆

最初の論文・分析単位としては、以下に絞るのが堅い。

> 2005年以降Jリーグ出場日本人選手の育成経路とキャリア到達点

この場合、指導者ネットワークは第2論文または拡張分析に回す。

初期分析では、以下のデータ構築を優先する。

- 2005年以降にJ1/J2/J3公式戦に出場した日本国籍選手
- 生年、ポジション、所属クラブ履歴
- 育成年代の所属経路
- Jクラブアカデミー、高校、大学、街クラブ、JFAアカデミー経験
- 特別指定選手認定歴
- プロ初出場年齢
- U21時点の出場時間
- J1到達・J1定着
- 海外移籍
- 代表選出

分析手法としては、まず記述統計、ロジスティック回帰、生存分析を中心に置く。

機械学習は因果推論ではなく、特徴量探索と予測精度確認に使う。
