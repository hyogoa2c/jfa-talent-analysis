# 所属クラブ欄の取り込み評価（2026-07-26）

用途: SAP v3 の測定手順変更の根拠。外部レビュー（`docs/review_results_phase1_corrigendum.md`）
Q7「標的化された曝露測定の改善」への対応。

**状態: era1 の検証待ちで結論は保留。** era1 のフル抽出取得が完了するまで採用可否を決めない。

## 1. 何が問題だったか

`pathway_category` の測定は Wikipedia 記事の**散文セクション限定**で行われていた
（`PRE_PRO_SECTION_HEADINGS` = 来歴・経歴・高校時代 等）。`== 所属クラブ ==` の経歴リストは
対象外で、Gate A キュー 48 行のうちコンテキストに含まれていたのは 5 行のみ。

しかしこのリストは、多くの記事で**学歴のもっとも明快な記述**である。実際、人手レビューでは
レビュアーが個別に参照して修正していた（`reviewer_note` に記録、計 69 行）。つまり
**同じ情報源が一部の行にだけ非公式に適用されている**状態だった。

なお本リストは既にパース済みで、`data/interim/coach_network/player_institution_stints.csv`
（27,073 行）として存在する（コーチネットワーク構築時の副産物）。

## 2. 導出ロジック

`src/jfa_talent_analysis/club_history_pathway.py`。リストは時系列順なので、
**最初のプロ入り entry の直前にある最後の育成機関**を経路とする。これが散文にない情報である。

例（中町公祐）: 高崎高等学校 → 湘南 2004 → 慶應義塾大学 2008。
散文だけ読むと大学経路に見えるが、順序を見れば大学はプロ入り後である。

事故を避けるための規則（テストで固定）:

- **2種登録・特別指定はプロ入りではない**（`registration_formality=1` で除外）。
  これらは育成年代中のプロクラブ登録であり、経歴を早すぎる位置で切ってしまう。
- **年号を持つ少年団もプロ入りではない**（`birth_year + 16` の年齢ガード）。
- **育成段階が見つからなければ空欄**。`high_school` に倒さない（証拠不在 ≠ 高校）。
- 大学付属高校は `high_school`（散文分類器の機序 A と同じ）。

## 3. gold に対する精度

`determination=confirmed`・主要 3 経路のみ。

| gold | 一致 / 判定できた | 一致率 | stints なし |
|---|---|---|---|
| era1 | 0 / 0 | **評価不能** | 44 |
| era2 | 28 / 29 | 97% | 12 |
| fresh | 41 / 41 | 100% | 4 |

**era2+fresh 合計 69/70 = 98.6%。** 参考: 散文分類器の `auto_high_conf` 層の一致率は
era1 18/18・**era2 12/14 = 86%**（`reports/generated/measurement_funnel_by_era.md` §8.1）。

## 4. 散文分類器との食い違い（era2 適格標本）

両者ともラベルを出した 1,564 名で **一致 1,469（93.9%）/ 不一致 95**。

| 散文 → 所属クラブ | 件数 | 性質 |
|---|---|---|
| unknown → 各経路 | 36 | 純粋な回収（競合ではない） |
| university → high_school | 19 | プロ入り**後**の大学（中町型）。順序でしか解けない |
| high_school → j_club_academy | 17 | ユースと高校の同時在籍（SAP §1b）。順序で解ける |
| university → j_club_academy | 7 | 同上 |
| j_club_academy → university / high_school | 7 | 所属クラブ側が逆向きに主張する型 |

**gold があり両者が食い違った 12 例では、所属クラブ欄が 11 勝 1 敗。**

不一致の主要 2 型（計 36 件）は、いずれも**散文では構造的に判定できない順序の問題**であり、
所属クラブ欄が優位なのは機序的にも整合する。

## 5. era1 が未検証であることの意味

era1 の gold 44 名は**全員 stints を持たない**。原因は `player_institution_stints.csv` が
2014–2025 ユニバースのフル抽出からのみ構築されており、pre-2014 のみの選手が未処理であるため。
適格標本のカバレッジは **era1 59.7% / era2 91.3%（31.6pp 差）**。

**このまま取り込めば era 非対称な測定改善となり、レビュー Q4 が警告した差異的誤分類そのものを
作り込む。** したがって pre-2014 のフル抽出取得（`fetch_full_wikipedia_extracts.py`、逐次実行）
→ `extract_club_histories.py` によるパース → era1 gold での検証、を前提条件とする。

era1 で崩れうる具体的経路は、**古い記事における所属クラブ欄の書式差・完備度差**である。
これはパース率として測定できるので、精度と併せて確認する。

## 6. 採用案（era1 検証後に確定）

era1 の一致率が era2 と同水準（概ね 95% 以上）かつパース率が同水準なら:

- **両者がラベルを出し一致 → そのまま採用（高信頼）**
- **食い違い → 所属クラブ欄を採る**（§4 の 11:1 と機序的整合による）。ただし
  `j_club_academy → university/high_school` 型（7 件）は所属クラブ側が逆向きに主張する
  少数型なのでレビューへ回す
- **所属クラブ欄のみ → 採用**（unknown 36 件の回収）
- **散文のみ → 従来どおり**

era1 の一致率が era2 より明確に低い場合は、**Q4 の懸念が実データで裏付けられた**ことになるので、
全面併用ではなく「unknown の穴埋めのみ」に留めるか、era 別の誤分類率を Gate B の
バイアス分析に投入する。**どちらに転んでも Gate A の判断材料になる。**
