# Phase 1b SAP v3 追加照会（2026-07-26）

用途: 本文書を単体で外部レビュアー（Phase 1・Phase 1b SAP と同じく GPT-5.6 等）に渡す。
回答は `docs/review_results_phase1b_sap_v3.md` として保存し、反映のうえ Phase 1b の
確認的分析（H1b-2）に着手する。

**依頼の核心**: 前回レビュー（`docs/review_results_phase1_corrigendum.md`）の必須修正5項目を
反映し、SAP を **v3 として固定した**（`60a324e`）。チェックリスト8項目は自己申告で
満たしたと考えている。

**しかし、前回レビュー後に新しい測定手順（`所属クラブ` 欄由来の経路導出、SAP §1b-3）を
作って採用しており、これはレビュアーが一度も見ていない。** そして構造上、
**Gate A の通過判定がこの手順に全面的に依存している**——従来の散文分類器だけでは
era2 の gold 妥当性が「判定不能」となり、Gate A は停止する。

したがって「実行に進んでよい」という判定そのものが未評価の手順に乗っている。
**H1b-2 の封印実行より前に**、この 1 点を中心に助言をいただきたい。

**非対称性についての認識**: 先に照会して承認されれば失うのは時間だけである。先に実行してから
§1b-3 に異論が出た場合、その時点でアウトカムを見ているため **H1b-2 の確認的地位は
回復できない**。この非対称性が本照会の動機である。

**本文書にアウトカム結合の集計は一切含まれていない。** Phase 1b の outcome-linked 推定は
未算出・未閲覧である（SAP §固定の証跡と閲覧範囲の宣言）。

---

## 1. 前提（レビュアー向け最小限の背景）

日本人プロサッカー選手の**観察研究**。曝露 = 最終プロ前育成経路
（`j_club_academy` 基準 / `high_school` / `university`）、主アウトカム = 25 歳までの J1 到達。
因果効果ではなく関連を主張する。

**Phase 1b の確認的検定は 1 本のみ**: `pathway × era` 交互作用の共同両側尤度比検定
（era1 = born 1981–89、n=1,193 / era2 = born 1990–99、n=1,722）。
主報告尺度は era 別の標準化リスク差と、**その差の差（DID）**。

曝露はこれまで **Wikipedia 記事の散文セクション**（`来歴`・`経歴` 等）からのヒューリスティック
分類器 + 曖昧例の人手レビューで測定してきた。

## 2. 前回レビュー以降に起きたこと

前回レビューの必須修正5項目に対応する過程で、Gate A（outcome 非結合の測定ゲート）が
**2 回停止した**。

**停止1: レビュー未完了**。適格標本内の 43 行（era1 18・era2 25）がどのレビュー済みキューにも
存在しないことが判明。`pathway_review_queue_gate_a.csv`（48 行）として生成・レビューし、
**38 行確定・5 行変更・5 行判定保留**。判定保留の理由は全件同じで、
「Wikipedia の `所属クラブ` 欄に学校名の記載があるが、その欄は当時の測定手順の対象外であり、
5 行だけ別ソースで埋めると測定が不統一になる」であった。

**停止2: gold 妥当性**。gold 各 50 名は `unknown_label` / `no_confirmed_article` 層を意図的に
過剰抽出した層化標本なので（各 era で 22/50）、全 50 名を分母にした一致率は era の精度推定に
ならない。era 間で比較可能な `auto_high_conf` 層に限ると:

| era | 散文分類器の一致 | 95% CI (Wilson) | 判定 |
|---|---|---|---|
| era1 | 18/18 = 100% | [82%, 100%] | 合格 |
| era2 | **12/14 = 86%** | **[60%, 96%]** | **判定不能**（CI 下限 < 80%） |

前回レビュー Q2 §③「主要セルの検証数が不足なら合格ではなく判定不能とする」に従い、
**era2 を判定不能とした**。この時点で Gate A は通らない。

## 3. 新規測定手順 §1b-3 の内容と検証結果

上記の停止2つに共通して現れたのが、これまで測定手順の対象外だった
`== 所属クラブ ==` の経歴リストである。

### 3.1 なぜ作ったか

このリストは多くの記事で**学歴のもっとも明快な記述**であり、実際**人手レビュー時には
レビュアーが個別に参照して修正していた**（`reviewer_note` に記録、計 69 行）。つまり
**同じ情報源が一部の行にだけ非公式に適用されている**状態だった。本手順はその一貫性の回復である。

なお本リストは既にパース済みで、コーチネットワーク構築時の副産物として存在していた
（新規のデータ収集ではなく、既存資産の測定手順への編入である）。

### 3.2 導出ロジック

リストは時系列順なので、**最初のプロ入り entry の直前にある最後の育成機関**を経路とする。
これは散文にない**順序情報**であり、`ユース→大学→プロ` と `ユース→プロ→大学` を分離できる。

例（中町公祐）: 高崎高等学校 → 湘南 2004 → 慶應義塾大学 2008。
散文だけ読むと大学経路に見えるが、順序を見れば大学はプロ入り**後**である。

事故防止規則（テストで固定）: ①2種登録・特別指定はプロ入りではない（育成年代中のプロクラブ
登録）、②`birth_year + 16` 未満の entry はプロ入りではない（年号を持つ少年団）、
③育成段階が見つからなければ空欄（`high_school` に倒さない）、④大学付属高校は `high_school`。

### 3.3 era 非対称なカバレッジ差は解消済み

当初 era1 のパースカバレッジは 59.7% しかなく（stints が 2014–2025 ユニバースからのみ構築されて
いたため）、そのまま採用すれば **era 非対称な測定改善**を作り込むところだった。
pre-2014 のフル抽出 1,062 名を追加取得してから採用した。

| | 取得前 | 取得後 |
|---|---|---|
| era1 カバレッジ | 59.7% | **90.4%** |
| era2 カバレッジ | 91.3% | 92.5% |
| **差** | 31.6pp | **2.1pp** |

### 3.4 gold に対する精度

`determination=confirmed`・主要 3 経路のみ。

| gold | 一致 | 95% CI (Wilson) |
|---|---|---|
| era1 | **31/31 = 100%** | [89%, 100%] |
| era2 | 28/29 = 97% | [83%, 99%] |
| fresh（別途抽出） | 45/45 = 100% | — |

合計 **104/105 = 99.0%**。**両 era とも CI 下限が 80% を超える**ため、
この手順は §6b-3 の gold 妥当性条件を通す（散文分類器は era2 で通らない）。

**留保**: era1 n=31 / era2 n=29 で区間はなお広い。「合格」は CI 下限が閾値を上回るという意味で
あって、誤分類率を精密に推定したという意味ではない。SAP はこの区間幅を Gate B の確率的
バイアス分析へ伝播させると規定した。

### 3.5 採用規則（v3 で固定した内容）

両手順を算出したうえで:

- 両者が一致 → 採用（`source=both_agree`）
- **食い違い → 所属クラブ欄を採る**（`source=club_list_over_prose`）。ただし
  `j_club_academy → university/high_school` 型は所属クラブ側が逆向きに主張する少数型なので
  **レビューへ回す**
- 所属クラブ欄のみ → 採用（`unknown` の回収）
- 散文のみ → 従来どおり
- 両者ともなし → `unknown`

「食い違い時に所属クラブ欄を採る」根拠は、**gold があり両者が食い違った 12 例で
所属クラブ欄が 11 勝 1 敗**であること、および不一致の主要型が
**散文では構造的に判定できない順序の問題**であることの 2 点である。

## 4. 助言をいただきたい論点

### Q1. §1b-3 の採用可否（**本照会で最も判断を仰ぎたい論点**）

**こちらの判断**: 採用してよい。根拠は §3.4 の gold 精度、§3.5 の 11 勝 1 敗、
機序的整合（順序情報は散文に存在しない）、および「人手レビューで既に非公式に使われていた
情報源の一貫適用」という性格。

**懸念**:

1. **置換規則の根拠が 12 例に乗っている。** 「食い違ったら新手順を採る」は強い規則だが、
   その直接証拠は gold で両者が食い違った 12 例（11 勝 1 敗）である。
   二項の 95% CI は [65%, 99%] 程度で、規則の強さに比べて標本が薄い。
2. **Gate A 通過がこの手順に依存している。** 散文分類器だけなら era2 は判定不能で停止する。
   「新手順を採用したから Gate A が通った」という構造は、**ゲートの目的（測定不備で止める）
   に照らして許容されるか**。
3. 本手順は**前回レビュー Q7（標的化された曝露測定の改善）への回答**として作ったものだが、
   Q7 が想定していたのは外部ソースによる追加検証であって、新しい自動導出の追加ではない
   可能性がある。

**具体的に伺いたいこと**: この採用を (a) そのまま認める、(b) `unknown` の穴埋めのみに
限定する（食い違い時は散文を維持）、(c) 置換規則の根拠となる gold を増やすまで保留する、
のいずれが妥当か。

### Q2. §1b-3 の適用が era 非対称であること（**新規開示・重要**）

**本照会の起草時に再集計して判明した事実であり、SAP v3 固定時には把握していなかった**
（v3 固定時点では era2 のみ集計していた）。前回レビュー Q4（era 間の差異的誤分類）に
直接関わるため、そのまま開示する。**SAP 側にも v4 として同じ事実を追記済み**
（分類 = 運用明確化・outcome 非結合の事実追加。主仕様は不変）。

適格標本で両手順を突き合わせた結果（定義: 散文の `unknown` は「ラベルなし」として扱い、
主要 3 経路 + `grassroots_club` / `jfa_academy` を対象）:

| | era1 | era2 |
|---|---|---|
| 適格 | 1,193 | 1,722 |
| 両者ともラベルあり | 1,014 | 1,548 |
| **一致** | **921（90.8%）** | **1,488（96.1%）** |
| **不一致** | **93（9.2%）** | **60（3.9%）** |
| 所属クラブのみ（`unknown` 回収） | 52 | 36 |
| **ラベルが変わる合計 / 適格** | **145 / 1,193 = 12.2%** | **96 / 1,722 = 5.6%** |

不一致の内訳（上位）:

| 散文 → 所属クラブ | era1 | era2 | 性質 |
|---|---|---|---|
| `university` → `high_school` | 39 | 19 | プロ入り**後**の大学（中町型）。順序でしか解けない |
| `high_school` → `j_club_academy` | 15 | 17 | ユースと高校の同時在籍（SAP §1b-1） |
| `university` → `j_club_academy` | 10 | 7 | 同上 |
| **`j_club_academy` → `university`** | **9** | **4** | 所属クラブ側が逆向きに主張（レビュー行き） |
| **`j_club_academy` → `high_school`** | **6** | **3** | 同上（レビュー行き） |
| `high_school` → `university` | 6 | 3 | — |

**こちらの読み**: 2 つの解釈があり、現状のデータでは決着していない。

- **(a) era1 の散文測定が実際に劣っており、所属クラブ欄がそれを是正している。**
  era1 の記事は古く、散文が薄い一方で経歴リストは定型的に残りやすい。
  gold はこの読みを支持する（era1 31/31、しかも散文分類器の era1 は 18/18 なので
  「era1 の散文が壊れている」とまでは言えないが、needs-review 率は era1 が +6.6pp 高い）。
- **(b) 所属クラブ導出自体が era1 で劣化しており、不一致の多くが新手順側の誤り。**
  gold（era1 n=31）はこれを否定する方向だが、31 件で 9.2% の不一致の内訳を
  保証できるほどの分解能はない。

**懸念**: (a) が正しければ本手順は era1 の測定を改善し、交互作用の推定を**改善**する。
しかし (b) が正しければ、**era1 にだけ誤りを注入する差異的誤分類**となり、これは前回レビュー
Q4 が「対称誤分類の仮定では再現できない」と警告した型そのものである。
とくに `j_club_academy → 他` の逆向き型が era1 に厚い（15 件 vs 7 件）ことは、
**基準カテゴリの構成が era1 で選択的に変わる**ことを意味する。

**具体的に伺いたいこと**: (1) この非対称性は §1b-3 の採用を止める理由になるか、
(2) 止めないとして、Gate B の誤分類シナリオ（現在 S1–S8 を事前指定）に
「§1b-3 の適用有無」を明示的なシナリオとして追加すべきか、
(3) 追加 gold（下記 Q5）の層化軸に「両手順が食い違った行」を必ず含めるべきか。

### Q3. 基準カテゴリの汚染を「直さない」判断

**新規に見つけた問題**: `j_club_academy` の判定正規表現が素の「ユース」「U-1x」に一致するため、
**J リーグ加盟クラブ以外の育成組織も基準カテゴリに入る**。
era1+era2 の `j_club_academy` 580 件を点検した内訳:

| 種別 | 件数 |
|---|---|
| J クラブ下部組織と言えないもの（三菱養和・FCみやぎバルセロナ・アミーゴス鹿児島・塩釜FC・横河武蔵野FC・FCグラシア相模原・常総アイデンティ 等） | 約 14 |
| 海外クラブ（レスター・ロリアン・リーベルプレート） | 3 |
| J 参入時期により境界が動くもの（Y.S.C.C.・読売日本SC） | 6 |
| **合計** | **23 / 580 = 4.0%** |

**こちらの判断**: v3 では**直さない**。理由は、この正規表現は**散文分類器と共有**されており
Phase 1 でも同じ性質を持つため、ここだけ定義を変えると **Phase 1 と Phase 1b の曝露定義が
不整合**になるから。SAP §13 に限界として記録し、Gate B の S4（非対称誤分類シナリオ）で扱う。

**懸念**: 前回レビュー Q4 は「academy への一方向誤分類は基準群の outcome risk を変える」と
名指しで警告した。4.0% は小さいが、**基準カテゴリ**であること、および Q2 の非対称性と
重なりうることを考えると、限界として記録するだけで足りるか自信がない。

**具体的に伺いたいこと**: (a) 記録＋S4 で足りる、(b) Phase 1 も含めて定義を修正すべき
（= Phase 1 の再 corrigendum）、(c) Phase 1b のみ修正し不整合を明記する、のいずれが妥当か。

### Q4. Gate A 判定の循環性

Gate A の停止事由のうち、**2 つとも §1b-3 の採用で解消している**。

- 停止1 の判定保留 5 行 → 保留理由が「所属クラブ欄が測定手順の対象外」だったので、
  採用により理由が消滅し、5 行すべてが高確信で解決した。
- 停止2 の gold 妥当性 → §1b-3 が両 era で合格したことで通過した。

**こちらの認識**: 手続きとしては、①停止を記録し、②手順を作り、③**outcome 非閲覧のまま**
gold で検証し、④採用を SAP に「推定に影響しうる定義変更」として明記した、という順序を
踏んでいる。恣意的な後付けではないと考えている。

**懸念**: それでも「ゲートを通すために手順を追加した」という外形は残る。
とくに判定保留 5 行を、**同じ v3 で採用した手順で解決している**のは自己参照的に見えうる。

**具体的に伺いたいこと**: この手続きは許容されるか。許容される場合、
第三者が事後に検証できるようにするため、v3 に追加で記録すべき事項はあるか。

### Q5. MID = 3pp と追加 gold の位置づけ

前回レビュー Q2 は「最小重要差は研究者が根拠を付して v3 で固定すべき（5pp は普遍的な保証ではない）」
とした。これを受けて固定した内容:

**MID = 絶対 3pp（DID 尺度）**。根拠は Phase 1 の大学ペナルティ **−26.3pp**
[−33.0, −19.2]（正本既報）の**約 1 割**。言明は「測定誤差だけで既知の経路格差の約 1 割に
相当する era 差を作れてしまうなら、格差の時代変化は確立していない」。
判定規則は **3pp 一本**とし、報告時に 5pp での判定も併記する（閾値選択への異論を無力化するため。
判定規則が二本あるという意味ではない）。

**追加 gold = 各 era 100 件（現状 era1 31 / era2 29、追加約 140 件）**。これは MID からの逆算で、
誤分類率 CI 幅 ≈ 7.4pp → DID 分解能 ±2.8pp < MID 3pp を目標とする。
**Gate A の前提条件ではなく Gate B の前提条件**として位置づけた——31/29 は既に CI 下限 80% を
超えるので Gate A は待たないが、その分解能では Gate B の停止条件（DID が 3pp 以上動くか）を
判定できないため。

**こちらの懸念**: 記載にあたって「実質的意義（主効果比）」と「実行可能性（gold 規模による
分解能）」を混ぜないよう分離した（混ぜると閾値をデータの都合で決めたと読まれるため）。
順序は **MID → gold 規模の逆算**であって逆ではない、と明記した。この整理で十分か。

**具体的に伺いたいこと**: (1) 3pp という水準と根拠は妥当か、(2) 追加 gold を Gate A ではなく
Gate B の前提に置く設計は妥当か、(3) 100 件/era という規模は目的
（**散文分類器の検証ではなく、所属クラブ導出の誤分類率の区間を狭めること**）に照らして適切か。

## 5. 実行順序（参考・v3 §11 で固定済み）

1. §1b-3 の採用規則をパイプラインへ実装し、確定ラベルを再生成 → ラベルハッシュ更新
2. 追加 gold 約 140 件の層化収集（outcome 非閲覧・外部ソース二者独立判定・抽出確率記録）
3. ラベル・コード・seed のロック
4. **H1b-2 と Gate B を単一スクリプトで封印実行**（途中結果を見て仕様を変更しない）
5. その後に、事前固定済みのプール解析（別 estimand）を実行

**プール outcome を H1b-2 より先に見ない**運用を固定した（見た場合、H1b-2 は明示的に
探索へ降格する）。本照会は手順 1–2 と並行して行っており、**手順 4 には入っていない**。
