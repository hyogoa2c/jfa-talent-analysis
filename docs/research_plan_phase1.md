# Phase 1 研究計画・事前分析計画（SAP）

作成日: 2026-07-18
根拠: 外部レビュー `docs/review_results.md`（2026-07-18）の推奨に基づき、主リサーチクエスチョン・
対象者フロー・変数定義・主分析計画を固定する。**本計画確定後の分析は確認的（confirmatory）として
扱い、これまでの全分析は探索的（exploratory）として位置づけ直す。** 計画からの逸脱は本文書に
追記の形で記録する。

## 0. 用語の定義

後段の判断がぶれないよう、本計画で用いる中心用語を定義する（2026-07-18 の PR #8 レビューメモ
`docs/conversation_memo.md` に基づく追加）。

- **育成段階**: プロ入り前に選手が所属しうる機関種別。J クラブアカデミー（クラブユース）、
  高校（部活動）、大学、JFA アカデミー、その他（グラスルーツ等）。
- **育成経路**: 選手がプロ入りまでに経た育成段階の系列（例: 高校→大学）。
- **最終プロ前育成経路**: プロ初所属直前の育成段階（変数 `pathway_category`）。
  **本論文の評価対象（曝露変数）はこれとすることに合意済み**（2026-07-18）。
- **多経路（＝多最終経路）**: 日本の育成制度において複数の最終経路（高校・クラブユース・大学）が
  併存していること。当初構想の「多経路」はこの意味である。個人内で複数段階を渡る経路
  （例: 高校→途中からクラブユース）はおそらく特殊例であり、記述にとどめる（§7）。
- **指導者構造**: 育成機関における指導者の配置・経歴・系譜のネットワーク。Phase 2 の対象であり
  現在凍結中（§9）。

## 1. リサーチクエスチョン（二層構造）

**上位問い（研究プログラム全体を導く。本論文では直接検証しない）**

> 日本サッカーにおける育成経路と指導者構造は、選手のキャリア形成とどのように関係しているか。

**Phase 1 主 RQ（本論文で答える）**

> 2014–2025 年に J1・J2・J3 公式戦への出場が観測された日本人選手において、最終プロ前育成経路は、
> その後の J1 到達、海外クラブ移籍、代表選出とどのように関連するか。

**Phase 1 副 RQ**

> これらの関連は、出生コホートおよび育成年代代表選出歴を調整した後にも観察されるか。

**Phase 2 探索的 RQ（独立した副研究。追加データ取得まで凍結）**

> 公開情報から育成年代の監督を合理的に特定できる選手について、所属機関と出生コホートを
> 調整した後に、監督間のキャリア成果差を検出できるか。
> （現状の答え: 検出できなかった。順列 p≈0.30。`docs/results_canonical.md` 参照）

## 2. 仮説

- **H1**: 最終プロ前育成経路によって J1 到達確率は異なる。
- **H2**: 最終プロ前育成経路によって海外移籍および代表選出確率は異なる。
- **H3**: 経路と成果の関連の一部は、育成年代代表選出で測定したプロ入り前の選抜差によって
  説明される（調整により関連が減衰する）。
- **H4**: 経路と成果の関連は出生コホートによって異なる。

注: 「多経路育成仮説」は §0 の定義どおり**多経路＝多最終経路**に絞る（2026-07-18 合意）。
この定義のもとでは、主要 3 最終経路間の成果を比較する H1・H2 が本仮説の検証にそのまま対応する
（初版の「検証対象から除外」を撤回）。個人内の複数段階経験を保持する変数群（§7）は
記述・探索として扱い、確認的検定はしない。

## 3. 適格条件と観測窓

- **理念上の母集団**: 2005 年以降にプロ入りした日本人サッカー選手（データ収集計画の当初定義）。
- **実際の観測窓**: J.League Data Site（SFPR01）の出場記録が利用可能な **2014–2025 年**。
  両者は区別して記述し、混同しない。
- **適格条件**: 2014–2025 年に J1/J2/J3 公式戦出場（appearances>0、名簿登録のみは不可）が
  1 試合以上観測され、SFIX03 選手台帳と同定できた日本人選手。
- **既知の打ち切り構造**: 2014 年以前デビューの選手は初期キャリアが観測されない
  （出生 1990 年以前は全員、1990–94 年生まれの 85% がリスク）。`reached_j1_ever` は
  Wikipedia バックフィルで補正済み。感度分析として出生年下限制限を実施する（§6）。

## 5. アウトカムの区別

- **主アウトカム**: J1 到達（`reached_j1_ever`: SFPR01 出場 + Wikipedia デビュー行バックフィル）
- **副アウトカム**: 海外クラブ移籍（`moved_overseas_final`）、A 代表選出
  （`national_team_categories` から導出。any-selection は youth 特徴量とのリーク回避のため
  副アウトカムには使わない）
- **探索的アウトカム**: any_national_team_selection、デビュー年齢、時代交互作用、多経路記述

## 6. 主分析モデルの指定（確認的分析）

- **モデル**: アウトカム別ロジスティック回帰。曝露 = pathway_category（基準 j_club_academy）。
- **出生コホート調整**: 線形 birth_year ではなく、**制限付き 3 次スプライン（または 5 年幅
  コホートダミー）**。海外移籍モデルでは非単調性（1990–97 山）が既知のため必須。
- **クラスター構造**: 最終プロ前機関が同定できる選手（所属クラブ行パース済み 3,342 名）については
  機関クラスターロバスト標準誤差を主とする。機関不明選手を含む全標本では通常 SE とし、
  両者を併記する。
- **副 RQ モデル**: 上記 + `youth_selected`（および感度として youth_cat_count・
  earliest_youth_age）。
- **逐次調整モデル**（海外移籍のみ）: + reached_j1。**因果媒介分析とは呼ばない**。
- **報告様式**: OR に加えて**調整済み予測確率と経路間リスク差**（平均限界効果）を必ず報告する。
- **ポジション調整**: `position_master`（GK/DF/MF/FW、player-season 粒度で欠測 0 を確認済み。
  選手単位への集約規則: 最頻値）を共変量として追加した感度モデルを実施する。主モデルには
  入れず、サブグループ解析もしない——ポジション別の解釈には踏み込まない（事前方針）。

### 感度分析（事前指定）

1. 出生年下限制限（≥1995 / ≥2000）——打ち切りバイアス評価（既存実装あり）
2. `pathway_category_source = human_reviewed` のみ／auto_high_confidence を含む全体の比較
   ——分類誤り影響
3. 代表歴「該当なし」の偽陰性率 2.2%（JFA 裏取り実測値）を用いた確率的バイアス分析
4. 同定不能 634 名の欠測機構評価: 観測可能な特徴（出場時間 Tier・出生年）の比較と、
   逆確率重み付けによる主モデル再推定
5. 機関クラスター SE の有無比較

### 生存時間分析の扱い

出生時点起点の経路別 Kaplan–Meier は、**大学経路が大学進学年齢まで確定しない**という
不死時間バイアスの構造を持つため、**主分析から降格し探索的付録とする**。時間原点をプロ入り時点
（初観測シーズン）に取り直した到達速度分析を代替として検討するが、Phase 1 論文の必須要素とは
しない。

## 7. 経路変数の再設計（記述・探索）

排他的な最終経路分類に加えて、パース済み所属クラブ行（`player_institution_stints.csv`）から
以下を構築する（**在籍年不要のフラグが主体なので追加データ収集は不要**）:

- `has_j_club_academy` / `has_high_school` / `has_university` / `has_jfa_academy`（在籍経験フラグ）
- `pathway_count`（経験した育成段階数）、`pathway_sequence`（段階の順序列）
- 可能なら特別指定選手経験・各段階の開始/終了年齢（学年コホート補完を再利用）

これらは個人内の多段階経路（§0 のとおり特殊例と想定）の頻度と分布を把握するためのもので、
Phase 1 では記述統計と探索的分析に用い、確認的検定はしない。多経路育成仮説そのものは
多最終経路として H1・H2 で扱う（§0・§2 注）。

## 8. 用語の規律（全文書・論文共通）

- 「効果」→「関連」（因果効果の推定は本設計では不可）
- 「媒介分析・直接効果」→「逐次調整モデル・J1 到達調整後の残存関連」
- 「選抜効果で説明され尽くす帰無仮説を否定」→「観測可能な早期選抜指標を調整しても負の関連は残った」
- 「非線形構造は存在しない」→「現在の特徴量・標本・設定では RF による明確な予測性能改善は
  確認されなかった」
- 「監督効果は検出されなかった」を「監督効果は存在しない」と読み替えない

## 9. Phase 2（指導者研究）の凍結条件と再開条件

現状: 防御可能な在籍年補完のもとで個別監督効果は非検出（p≈0.30）。以下のいずれかが得られるまで
新規の監督調査・分析は行わない:

1. 機関の年度別スタッフ名簿（監督割当誤差を ±1 年未満にできる一次資料）
2. 選手の入学・入団時点の能力指標（推薦・セレクション評価等）
3. 同一機関内の監督交代を利用できる設計（イベントスタディ／階層モデル）が成立する標本

## 12. 将来拡張（別トラック）: 2013 年以前の出場記録バックフィル

要望（2026-07-18、`docs/conversation_memo.md`）: 対象母集団を J リーグ発足期まで広げ、
1999–2005 / 2005–2015 / 2015–2025 の 3 期比較（2005 年 JFA 三位一体計画のターニングポイント
前後の比較）を可能にしたい。J リーグ選手出身監督の経歴データの補強にもなる。

初期実現性調査（2026-07-18 実施）:

- J.League Data Site の静的アーカイブ「過去の試合記録」
  （https://data.j-league.or.jp/SS/jpn/team/index.html）に **1999–2013 年の
  年度×チーム×大会ページが約 1,200 件**存在することを確認。
- ページは Shift_JIS の静的 HTML で、**選手別の出場試合数・出場時間・得点・節別出場記録**
  （先発○・キャプテン C・ベンチ SUB 等）を含む（鹿島アントラーズ 1999 J1 1st ステージの
  ページで確認）。
- 制約: 選手名はリンクなしのプレーンテキストであり、SFIX03 選手 ID との突合は
  氏名×チーム×年度ベースの同定になる（既存の同名選手解決ツール
  `suggest_identity_overrides_from_profiles.py` の拡張が必要）。生年月日はページに含まれない。

**Phase 1 の観測窓（2014–2025）と適格条件（§3）は変更しない。** バックフィルは独立した
データ収集トラックとして実施し、成立した場合の 3 期比較は Phase 1b または別研究
（H4 の時代交互作用の拡張）として、実施前に本 SAP と同様の計画固定を行う。
