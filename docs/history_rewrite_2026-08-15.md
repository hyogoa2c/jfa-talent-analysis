# 履歴の書き換えの記録（2026-08-15）

本リポジトリの git 履歴は 2026-08-15 に一度書き換えられている。
**論文が「意思決定の系列を独立に監査できる」と述べる根拠に直接関わるため、
何をしたのか・何が変わっていないのかをここに残す。**

## 何をしたか

全 221 コミットの author / committer の**メールアドレスのみ**を置換した
（`git-filter-repo --mailmap`）。個人の連絡先を公開リポジトリに載せないための措置であり、
研究内容とは無関係である。

置換後、GitHub 側に孤立オブジェクトが残り旧コミットが API から取得できる状態だったため、
リポジトリを削除して同名で再作成し、書き換え後の履歴のみを push した。
旧ハッシュが解決しないことを API で確認済み。

## 何が変わっていないか

| 項目 | 状態 |
|---|---|
| ファイルの内容 | **不変**（`main` の tree ハッシュは書き換え前後で `cd127191a08e` のまま） |
| コミットの作成日時 | **不変**（例: SAP v8 の固定点は 2026-07-29 05:51:13 +0900 のまま） |
| コミットメッセージ | 不変 |
| ブランチ構成 | 不変（12 本すべて復元） |
| **コミットハッシュ** | **変わった**（親のメタデータが変われば SHA も変わるため） |

**変わったのはハッシュと著者メールだけで、研究の実体は 1 バイトも動いていない。**
tree ハッシュが一致することがその証拠である。

## 事前指定の証跡への影響

SAP（`docs/research_plan_phase1b.md`）は各版の固定点をコミットハッシュで参照している。
書き換えでハッシュが変わったため、**文書中の参照を新しいハッシュへ機械的に更新した**。
対応は下表のとおりで、更新は全文書 7 ファイル・22 箇所。

**この操作は事前指定の主張を弱める。** 旧ハッシュを含む記録（本記録より前に作成された
外部のコピー・レビュー依頼文書など）と現行リポジトリは、ハッシュでは直接照合できない。
照合できるのは**内容・日時・順序**である。SAP の版ごとの差分表（v3 → v15）は
「いつ・何を・なぜ変えたか・その時点で outcome を見ていたか」を本文に記録しており、
**事前指定の主たる証拠はハッシュではなくこの差分表そのもの**である。
